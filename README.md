# NLP Practicals

This repo has a bunch of NLP programs written in Python using NLTK and spaCy. Each program covers a different concept — tokenization, stemming, lemmatization, stop-word removal, POS tagging, parsing, chunking, and named entity recognition.

---

## Programs

### 1. Tokenization of Sentences and Words

Splits input text into individual sentences and words using both NLTK and spaCy.

Libraries: NLTK, spaCy

---

### 2. Stemming and Lemmatization

Applies stemming and lemmatization to sample text. Stemming chops words down to a root-like form, lemmatization gets you the actual base word.

Libraries: NLTK, PorterStemmer, WordNetLemmatizer

---

### 3. Stop-word Removal

Filters out common words like articles and conjunctions from text using NLTK's built-in English stop-word list.

Libraries: NLTK, NLTK Stopwords

---

### 4. Part-of-Speech Tagging

Tags each word in a sentence with its grammatical role — noun, verb, adjective, and so on.

Libraries: NLTK, POS Tagger

---

### 5. Parsing and Chunking using RegEx and spaCy

Does syntactic analysis two ways: regex-based chunking with NLTK and dependency parsing plus noun-chunk extraction with spaCy.

Libraries: NLTK, RegexpParser, spaCy

---

### 6. Named Entity Recognition

Uses spaCy to pick out named entities from text — people, places, organizations, dates, etc.

Libraries: spaCy, en_core_web_sm

---

## Tech Stack

Python, Google Colab, NLTK, spaCy

---

## How to Run

All programs run in Google Colab. The required libraries and spaCy models are installed inside each notebook so nothing extra needs to be set up.
